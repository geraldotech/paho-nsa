NSA — estudo dos joins

Exemplo local usando nsa-profiles.json, nsa.json, activity.json e workplan.json.

1. Organização selecionada

2. Ciclos encontrados por NSAs.NSAProfileID

3. Filhos encontrados por ParentID = NSAs.ID

Cada bloco abaixo representa um ciclo. Assim, Workplans e Activities de ciclos diferentes não são misturados.

4. Filhos da organização cujo pai não está no export

Estes registros batem pelo NSAProfileID, mas o ciclo indicado pelo ParentID não existe em nsa.json.

Regra usada

Profile.ID
  = NSA.NSAProfileID          // encontra todos os ciclos da organização

NSA.ID
  = Activity.ParentID         // encontra Activities daquele ciclo
  = Workplan.ParentID         // encontra Workplans daquele ciclo

NSA.NSAProfileID
  = filho.NSAProfileID        // valida que o filho pertence à mesma organização
